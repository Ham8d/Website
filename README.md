# تراث ستور — نسخة جاهزة لـ Vercel

هذه نسخة ثابتة من الموقع؛ لا تحتاج قاعدة بيانات أو سيرفر دائم.

## الرفع إلى GitHub وVercel

1. فك ضغط الملف وارفع **محتويات المجلد** إلى مستودع GitHub جديد.
2. في Vercel اختر **Add New → Project** ثم استورد مستودع GitHub.
3. إذا طلب إعدادات البناء، استخدم:
   - Framework Preset: Other
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. اضغط Deploy. إعدادات البناء موجودة مسبقاً في `vercel.json`.
5. لربط `alturath-store.com`، أضف الدومين من **Project → Settings → Domains** واتبع سجلات DNS التي يعرضها Vercel.

ملفات الموقع الجاهزة للنشر موجودة داخل `dist/`، وملف `package.json` يحتوي أمر بناء بسيطاً حتى يتعامل Vercel مع المشروع مباشرة.

تنبيه: هذه نسخة النشر المبنية، وليست ملفات التطوير الأصلية. لتعديل تصميم الموقع، عدّل المشروع الأصلي ثم أعد بناء نسخة النشر.
